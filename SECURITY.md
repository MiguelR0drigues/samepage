# Security policy

SamePage holds a team's decisions and per-person tokens, so security reports are welcome and taken seriously.

## Reporting a vulnerability

**Do not open a public issue.** Report it privately through [GitHub's private vulnerability reporting](https://github.com/MiguelR0drigues/samepage/security/advisories/new).

Please include what is affected, how to reproduce it, and the impact you expect. You will get a first answer within 7 days.

## Supported versions

Only the latest commit on `main` gets security fixes.
